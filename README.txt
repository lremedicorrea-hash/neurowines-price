NEUROWINES — Wine Export Calculator V2.4

Validated build after V2.3 reverse-pricing bug review.

Key fixes:
- Forward ↔ Reverse pricing uses the same scenario and assumptions.
- EXW currency conversion now supports every currency offered by the app through one consistent USD cross-rate table.
- Destination retail price always uses destination currency.
- Reverse result always uses the selected EXW currency.
- Destination changes clear stale reverse target/results.
- Origin, destination and city lists remain alphabetically ordered.
- Reverse calculation blocks invalid FX rather than returning an absurd number.
- Static FX and commercial assumptions are explicitly planning references, not live data.

Important: regulatory/tax values are estimates unless specifically identified as a verified rule. The app is a planning tool, not customs advice.
