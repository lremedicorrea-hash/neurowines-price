NEUROWINES PRICE — APP V1 (PWA)

This package turns the V3.12 calculator into an installable Progressive Web App.

Included:
- Installable manifest
- App icons (180 / 192 / 512)
- Service Worker and offline app shell
- Install button and iOS/desktop installation guidance
- Standalone app display
- Original calculator functions preserved:
  EXW -> PVP
  Reverse PVP -> EXW
  Behind the Scenes editable assumptions
  Country-dependent city selectors

Publish the entire folder on HTTPS (GitHub Pages, Netlify, Cloudflare Pages, etc.).
PWA installation requires HTTPS, except on localhost during testing.
